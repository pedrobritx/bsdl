# Start here

1. Read polaris/constitution/README.md and relevant canonical principles/laws.
2. Read PROJECT_RULES.md and the approved task scope.
3. Read integration/README.md. Inspect the adopting project’s actual source, designs and tests; use agents/README.md to locate only the enabled/requested specialist guidance.
4. Check the applicable complete adopted policies; Draft placeholders grant no authority.
5. Work reversibly within approved scope, retain human gates and record material evidence/continuity.

Record adoption in the project’s constellation.json and task scope in a request record. The local planner checks selections and source provenance; a human/host agent still analyses and executes the request. Axis owns optional project-document templates. Canonical philosophical amendments remain separate explicit decisions.
