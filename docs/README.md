# Documentation ownership

Polaris owns the canonical polaris/ text, operating governance, agent registry, historical decisions and migration records. Axis maintains reusable project-document/specification templates. Meridian owns design guidance; Sentinel owns security requirements/evidence guidance. Filled project documents belong to the adopting project.

The file-level migration ledger distinguishes moves from derived local tooling/templates. Historical decisions keep their original wording and source scope; current ownership is recorded in the migration ADR.
