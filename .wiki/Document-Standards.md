# Document standards

Ownership and proportionate documentation are defined in [the operating rules](https://github.com/pedrobritx/polaris/blob/main/PROJECT_RULES.md) and [the documentation ownership index](https://github.com/pedrobritx/polaris/blob/main/docs/README.md). Axis supplies an optional [adopter catalogue](https://github.com/pedrobritx/axis/blob/main/docs/README.md).

[The document validator](https://github.com/pedrobritx/polaris/blob/main/automation/validate_docs.py) checks bounded front matter and relative Markdown file links. It does not prove anchors, external URLs, wiki links or application quality.
