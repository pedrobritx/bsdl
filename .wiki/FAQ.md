# Common adoption questions

Start requests with Polaris, or use any discipline directly. [The composition contract](https://github.com/pedrobritx/polaris/blob/main/integration/README.md) explains independent adoption, opt-outs and coverage gaps.

The planner validates selected handoffs; a host agent/human analyses and executes work. No model, cloud runtime, provider, full scaffold or complete set of disciplines is required. Axis templates are selected as needed rather than copied wholesale.
