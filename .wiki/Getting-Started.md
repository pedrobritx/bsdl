# Getting started

Use [the actual onboarding sequence](https://github.com/pedrobritx/polaris/blob/main/START_HERE.md). Select enabled disciplines using [the composition contract](https://github.com/pedrobritx/polaris/blob/main/integration/README.md). For standalone work start directly at the discipline’s AGENTS.md.

Adopt only the templates needed for the task. Draft policies grant no authority and a checked-in template proves no implemented behaviour.
