# Capability registry

Polaris retains the human owner and product coordination roles. Specialist engineering roles live in Axis, designer guidance in Meridian and security review in Sentinel. Roles are responsibility/review lenses; crossing a role label does not itself require repeated approval.

| Capability | Owner |
|---|---|
| Constitution, context and approval gates | Polaris |
| Architecture, engineering, project scaffolds and functional/performance evidence | Axis |
| Interface design, visual/interaction and accessibility evidence | Meridian |
| Security requirements, trust boundaries and security evidence | Sentinel |

Each capability remains independently useful; projects explicitly adopt governance and profiles. Security, accessibility, privacy and evidence remain obligations across all capabilities.
